## 第 1 课：认识 C 语言和「编程」这件事

### 1. 什么是「编程」

电脑不会思考，它只会：**按顺序执行指令**、**处理数据**。

- **编程（Programming）**：用电脑能理解的方式，把「你想让它做的事」一步步写下来。
- **程序（Program）/ 源代码（Source Code）**：写下来的这份说明书。

比方：电脑是听话但不会独立思考的工人；程序是详细的说明书；程序员是写说明书的人。说明书必须极其精确。

### 2. 什么是 C 语言

- **C 语言**：一种用来写「说明书」的**编程语言（Programming Language）**。
- 「语言」= 人与电脑交流的工具，就像中文、英文是人与人交流的工具。

### 3. 为什么要学 C（有什么用）

1. 基础中的基础，学懂后再学其他语言更容易。
2. 运行速度快。
3. 应用广：操作系统（Linux 内核大量使用 C）、嵌入式设备、数据库、游戏引擎等。

### 4. 关键概念：电脑只懂机器码

- 你写的 C 代码人看得懂，但 **CPU（Central Processing Unit，中央处理器）** 只认 **机器码（Machine Code）**，即二进制指令（如 `10100110`）。
- 因此需要「翻译」。

### 5. 关键概念：编译器（Compiler）

编译器是把**人写的 C 代码**翻译成**机器码**的软件。

```
C 代码（.c 文件） → [编译器翻译] → 可执行程序（.exe 文件） → 电脑运行
```

- `.c` 文件：源代码文件。
- `.exe` 文件：翻译后电脑能直接运行的程序。

> 重点：光有记事本写 `.c` 文件没用，**必须经过「编译」**才能运行。

### 测验与答案

1. **编程**用一句话说是在做什么？
   - 参考答案：把「你想让电脑做的事」用电脑能理解的方式一步步写下来。
2. 为什么电脑不能直接运行我们写的 C 代码？
   - 参考答案：电脑的 CPU 只认机器码，识别不了人类写的编程语言。
3. 「编译器」的作用是什么？
   - 参考答案：把 C 代码翻译成机器码 / 可执行文件。

## 第 2 课：搭建环境（编辑器 + 编译器 + 运行）

### 1. 需要什么

| 工具                | 作用                |
| ----------------- | ----------------- |
| **编辑器（Editor）**   | 写代码的地方，像写字的 Word  |
| **编译器（Compiler）** | 把 `.c` 翻译成 `.exe` |
| **运行**            | 双击 `.exe` 看结果     |

### 2. 专有名词：IDE

- **IDE = Integrated Development Environment（集成开发环境）**。
- 「集成」= 合在一起，把**编辑器 + 编译器 + 运行按钮**打包成一个软件。对新手最省事。

### 3. 推荐安装

- **Dev-C++**：老牌、体积小、专为初学者，推荐新手使用。
- **Code::Blocks**：更规范，界面略复杂。
- 说明：名字里的 **C++** 是另一种语言，但 Dev-C++ 同样能写、能编译**纯 C**。

### 4. 安装注意

- 安装路径用**纯英文**，如 `D:\DevCpp`，**不要**放在含中文的路径（如 `D:\文档\`）。

### 5. 备选：在线编译器

- 网址如 **onlinegdb.com**，打开网页即可写代码、点 Run 运行。
- 缺点：需联网、功能有限，不适合长期学习。

### 测验与答案

1. IDE 是什么？它和「编译器」是什么关系？
   - 参考答案：IDE 是集成开发环境，是「整合包」，把编辑器、编译器、运行按钮打包在一起；编译器只是其中负责翻译代码文件的组件。
2. 为什么光有记事本（写代码）还不够，非要装带编译器的工具？
   - 参考答案：电脑只认机器码，不写代码不行，不翻译成机器码程序就无法运行。

## 第 3 课：程序的基本结构

### 第一个 C 程序

```c
#include <stdio.h>

int main()
{
    printf("Hello, World!\n");
    return 0;
}
```

### 逐行解释

| 代码                   | 含义                      |
| -------------------- | ----------------------- |
| `#include <stdio.h>` | 引入一个现成工具包，以使用其中的功能      |
| `int main()`         | 程序的**入口**，电脑从这里开始执行     |
| `{ }`                | 一对花括号，把要做的事框起来（**代码块**） |
| `printf(...)`        | 一个**命令**，往屏幕上打印文字       |
| `"Hello, World!\n"`  | 要打印的内容，`\n` 表示「换行」      |
| `return 0;`          | 告诉系统「程序正常结束」            |
| `;`                  | 每句指令结尾的句号，**必须写**       |

### 专有名词

- `stdio` = **st**andar**d** **i**nput **o**utput（标准输入输出）。
- `printf` = **print f**ormatted（格式化打印）。
- **函数（Function）**：一段打包好、可重复使用来完成某个任务的代码。`main`、`printf` 都是函数。
- **语法（Syntax）**：这门语言的书写规则，写错会报错。

### 测验与答案

1. 程序的**入口**是哪个函数？从哪里开始执行？
   - 参考答案：`int main()`；从 `main` 左花括号后的第一行开始执行。
2. `\n` 是什么意思？
   - 参考答案：换行。
3. `#include <stdio.h>` 这一行在干什么？
   - 参考答案：引入一个工具包（头文件），以使用其中的功能。

## 第 5 课：安装 Dev-C++，在自己电脑上跑程序

### 本地开发 vs 网页版

- 网页版：代码、编译、运行都在别人服务器上。
- 本地版（Dev-C++）：代码存在自己电脑的 `.c` 文件里，编译与运行都在本机。

### 操作步骤

1. 浏览器搜索 `Dev-C++ 官网` 下载安装（认准官方）。
2. 安装时路径用纯英文，如 `D:\DevCpp`。
3. 菜单 `File → New → Source File` 新建源代码文件。
4. 输入代码后 `File → Save`，文件名 `hello.c`（**后缀必须是 `.c`**）。
5. 按 **F11**（Compile & Run）编译并运行。

### 三个按钮的区别

| 按钮                       | 作用                       |
| ------------------------ | ------------------------ |
| **Compile（编译）**          | 把 `.c` 翻译成 `.exe`，只翻译不运行 |
| **Run（运行）**              | 运行翻译好的 `.exe`            |
| **Compile & Run（编译并运行）** | 两件事一次做完，快捷键 **F11**      |

### 常见坑

- 后缀忘写 `.c` → 编译不了。
- 路径含中文 → 可能报错。
- 少写 `;` 或花括号 → 报语法错误。

## 第 6 课：编译背后发生了什么 + 认识「变量」

### 一、编译的 4 个步骤（了解即可）

1. **预处理（Preprocessing）**：处理所有 `#` 开头的行。`#include <stdio.h>` 就是把 `stdio.h` 的内容**原样复制粘贴**进代码。
2. **编译（Compiling）**：把 C 代码翻译成**汇编语言**（Assembler，一种低级语言）。
3. **汇编（Assembling）**：把汇编语言翻译成**机器码**，生成目标文件。
4. **链接（Linking）**：把 `printf` 等现成功能的机器码拼接进来，生成 `.exe`。

> 一句话：**编译器 = 翻译官 + 打包员**。

### 二、什么是「变量」

- **内存（Memory）**：电脑存放数据的地方，像一栋有很多房间的大楼。
- **变量（Variable）**：**给内存里的某个位置起一个名字**，以后用名字访问数据，不用记地址。
- 「变量」的「变」= 它存的值**可以改变**；相对的概念是**常量（Constant）**，值定下后不能变。

### 变量的两个关键概念

| 概念           | 含义            | 类比             |
| ------------ | ------------- | -------------- |
| **类型（Type）** | 这个变量存**哪种**数据 | 柜子分「只放书」「只放水果」 |
| **名字（Name）** | 你给变量起的标识      | 柜子上的标签         |

为什么要有类型：不同数据占空间、能做的运算不同，必须提前告诉电脑类型。

### 例子

```c
int age = 18;
```

| 部分    | 含义                         |
| ----- | -------------------------- |
| `int` | 类型，整数（**int**eger）         |
| `age` | 变量名                        |
| `=`   | **赋值**，把右边的值存进左边；不是数学的「相等」 |
| `18`  | 存入的数据                      |
| `;`   | 语句结束符                      |

### 测验与答案

1. `#include` 在预处理阶段到底干了什么？
   - 参考答案：把 `stdio.h` 文件的全部内容原样复制粘贴进代码。
2. 「变量」是什么？为什么需要它？
   - 参考答案：给内存位置起的名字；方便程序员用名字访问数据，不用记地址。
3. `int score = 95;` 各部分含义？
   - 参考答案：`int` 整数类型；`score` 变量名；`=` 赋值；`95` 要存的数据。

## 第 7 课：变量的命名规则 + 常见数据类型

### 一、命名规则

**铁律（必须遵守）**

1. 只能用**字母、数字、下划线 `_`**。
2. **不能以数字开头**。`age1` ✅，`1age` ❌。
3. **不能是关键字**。关键字 = C 保留、有特殊含义的词，如 `int`、`return`、`if`。

**建议（好习惯）**

1. 用有意义的英文名，`score` 好过 `a`。
2. C 语言**区分大小写**，`Age` 与 `age` 是两个不同变量。
3. 多单词可用下划线 `my_age` 或驼峰 `myAge`。

### 二、常见数据类型

| 类型       | 全称 / 含义          | 存什么    | 例子           |
| -------- | ---------------- | ------ | ------------ |
| `int`    | **int**eger，整数   | 整数     | `25`、`-100`  |
| `float`  | 浮点数（单精度）         | 小数     | `3.14`、`0.5` |
| `double` | 双精度浮点数           | 小数，更精确 | `3.14159265` |
| `char`   | **char**acter，字符 | 单个字符   | `'A'`、`'9'`  |

**要点**

- 整数与小数分开：存法与运算不同。注意整数除法 `7 / 2` 结果是 `3`（丢小数）。
- `double` 比 `float` 更大、更精确，**日常写小数建议用 `double`**。
- `char` 存单个字符，用**单引号** `'A'`；字符串用**双引号** `"ABC"`，别混。

### 例子

```c
int age = 18;
double price = 9.99;
char grade = 'A';
```

### 测验与答案

1. 哪些变量名不合法？`my_score`、`2ndPlace`、`int`、`total-Price`
   - 参考答案：`2ndPlace`（数字开头）、`int`（关键字）、`total-Price`（含减号）不合法；`my_score` 合法。
2. 存小数推荐用哪个类型？为什么？
   - 参考答案：`double`，比 `float` 更精确。
3. `char c = "A";` 对吗？为什么？
   - 参考答案：不对，`A` 是单个字符，应当用单引号 `'A'`。

## 第 8 课：用 `printf` 打印变量

### 1. 格式占位符（Format Specifier）

**占位符（placeholder）**：代表「这里要填一个值」的符号。

| 类型                 | 占位符  | 记忆                     |
| ------------------ | ---- | ---------------------- |
| `int`              | `%d` | **d** = decimal（十进制整数） |
| `double` / `float` | `%f` | **f** = float（浮点）      |
| `char`             | `%c` | **c** = char（字符）       |

> 什么类型配什么占位符，不匹配会打印出乱码。

### 2. 例子

```c
#include <stdio.h>

int main()
{
    int age = 18;
    double price = 9.99;
    char grade = 'A';

    printf("年龄是 %d\n", age);
    printf("价格是 %f\n", price);
    printf("等级是 %c\n", grade);

    return 0;
}
```

输出：

```
年龄是 18
价格是 9.99
等级是 A
```

理解：`printf("年龄是 %d\n", age);` 中，`%d` 是坑位，逗号后的 `age` 是要填入的值，运行时自动替换。

### 3. `%f` 控制小数位数

- `%f` 默认显示 **6 位小数**，如 `9.99` 可能显示为 `9.990000`。
- 用 `%.2f` 表示保留 2 位小数：

```c
printf("价格是 %.2f\n", price);   // 输出：价格是 9.99
```

### 测验与答案

1. 打印 `int`、`char` 各用什么占位符？
   - 参考答案：`int` 用 `%d`，`char` 用 `%c`。
2. 想让小数只显示 3 位，占位符写成？
   - 参考答案：`%.3f`。
3. `int n = 7; printf("数字是 %d\n", n);` 输出什么？
   - 参考答案：`数字是 7`。

## 第 9 课：用 `scanf` 从键盘输入数据

### 1. 为什么需要它

之前变量的值都写死在代码里，程序每次运行结果相同。`scanf` 让程序能**接收用户输入**。

- `printf` = **输出**（把数据送到屏幕）。
- `scanf` = **输入**（从键盘读取数据）。
- `scanf` = **scan f**ormatted（格式化扫描 / 读取），与 `printf` 是一对反义词。

### 2. 用法

```c
#include <stdio.h>

int main()
{
    int age;

    printf("请输入你的年龄：");
    scanf("%d", &age);

    printf("你输入的年龄是 %d\n", age);

    return 0;
}
```

运行过程：

```
请输入你的年龄：18      ← 键盘输入 18 回车
你输入的年龄是 18
```

### 3. 关键点：`&`（取地址运算符）

```c
scanf("%d", &age);
```

- `"%d"`：占位符，表示要读一个整数。
- `&age`：`&` 是**取地址运算符（Address-of Operator）**，表示「变量 `age` 的地址」。

**为什么 `printf` 不用 `&`，`scanf` 却要？**

- `printf` 是把变量的**值**拿出来打印，知道值就够。
- `scanf` 是要把输入的值**存进**变量，必须知道变量在**内存中的地址**才能存放。

打比方：要把东西送进房间，要知道**房间门牌号（地址）**。`&age` 就是 age 的门牌号。

> 记忆口诀：**输出用值，输入用地址。** 忘记 `&` 是新手最常犯的错误。

### 4. 常见占位符（与 printf 相同）

| 类型                 | 占位符  |
| ------------------ | ---- |
| `int`              | `%d` |
| `double` / `float` | `%f` |
| `char`             | `%c` |

（以后学字符串时，读取字符串的 `scanf` 反而**不加** `&`，是特例。）

### 测验与答案

1. `printf` 和 `scanf` 分别负责什么？
   - 参考答案：`printf` 负责把数据（变量值）输出到屏幕；`scanf` 负责把键盘输入的值存进变量。
2. `scanf("%d", &age);` 里的 `&` 是什么意思？`printf` 为什么不需要？
   - 参考答案：`&` 是取地址运算符，取变量 `age` 的地址；`printf` 只需知道变量的值即可。
3. 判断对错：`scanf("%f", price);` 对吗？为什么？
   - 参考答案：**错**。存进变量必须给地址，应为 `scanf("%f", &price);`。

## 第 10 课：运算符与计算

### 1. 什么是运算符

**运算符（Operator）**：对数据做运算的符号。

### 2. 算术运算符

| 运算符 | 含义      | 例子      | 结果   |
| --- | ------- | ------- | ---- |
| `+` | 加       | `5 + 3` | `8`  |
| `-` | 减       | `5 - 3` | `2`  |
| `*` | 乘       | `5 * 3` | `15` |
| `/` | 除       | `6 / 2` | `3`  |
| `%` | 取余（求余数） | `7 % 3` | `1`  |

> 乘法用 **`*`**，不是数学里的 `×`。

### 3. 大坑：整数除法

```c
int a = 7;
int b = 2;
printf("%d\n", a / b);   // 输出 3，不是 3.5！
```

- C 规定**整数 ÷ 整数 = 整数**，小数部分**直接丢掉**（非四舍五入）。
- 想得到小数，至少让其中一个操作数是小数（`double`）：

```c
double a = 7.0;
int b = 2;
printf("%f\n", a / b);   // 输出 3.500000
```

> 记住：**整数 ÷ 整数 = 整数（砍掉小数）**。

### 4. 取余运算符 `%`

求除法剩下的余数：

- `7 % 3` → 余 `1`。
- `10 % 2` → 余 `0`（能整除）。

用途：判断奇偶。`n % 2 == 0` 为偶数，`== 1` 为奇数。

### 5. 赋值运算符的简写

| 简写       | 等价于         |
| -------- | ----------- |
| `x += 5` | `x = x + 5` |
| `x -= 5` | `x = x - 5` |
| `x *= 5` | `x = x * 5` |
| `x /= 5` | `x = x / 5` |

### 测验与答案

1. 乘法用什么符号？`6 % 4` 结果？
   - 参考答案：`*`；`6 % 4` = 2。
2. `int a = 9; int b = 2;` 则 `a / b` 是几？为什么？
   - 参考答案：4；整数除以整数结果仍为整数，小数被丢弃。
3. `x = x + 3;` 的简写？
   - 参考答案：`x += 3;`。

## 第 11 课：`if` 判断——让程序会「思考」

### 1. 为什么需要它

程序需要**根据情况做出不同反应**（及格就祝贺、密码对了才放行）。这种结构叫 **选择结构（Selection Structure）**，C 用 `if` 实现。

### 2. 基本写法

```c
if (条件)
{
    条件成立时执行的代码
}
```

- `if` = 「如果」，条件放**圆括号**里，成立（为真）才执行**花括号**里的代码。

例子：

```c
int score = 60;

if (score >= 60)
{
    printf("及格了！\n");
}
```

### 3. 比较运算符（Relational Operator）

| 运算符  | 含义   |
| ---- | ---- |
| `==` | 等于   |
| `!=` | 不等于  |
| `>`  | 大于   |
| `<`  | 小于   |
| `>=` | 大于等于 |
| `<=` | 小于等于 |

> ⚠️ 超级大坑：`=` 是**赋值**，`==` 是**判断相等**。
> `if (x = 5)` ❌（赋值）；`if (x == 5)` ✅（判断）。

### 4. 完整例子

```c
#include <stdio.h>

int main()
{
    int score;
    printf("请输入分数：");
    scanf("%d", &score);

    if (score >= 60)
    {
        printf("及格了！\n");
    }

    return 0;
}
```

输入 75 打印「及格了！」；输入 50 跳过 if 块。

### 测验与答案

1. 条件写在什么符号里？成立时执行哪部分？
   - 参考答案：写在圆括号 `( )` 里；执行花括号 `{ }` 内的代码。
2. 判断相等用几个等号？`=` 又是什么？
   - 参考答案：判断相等用 `==`；单个 `=` 是赋值。
3. 补全判断 n 是否为偶数：
   - 参考答案：`if (n % 2 == 0)`。

## 补充课：数制（进制）

### 1. 什么是数制

- **数制（Number System）** 也叫**进制（Base / Radix）**：表示数字的一套规则。
- 核心是**基数（Base）**：每一位能用几个数字，以及「逢几进一」。

### 2. 常见的几种数制

| 名称                | 基数  | 用到的数字   | 进位规则  | 例子    |
| ----------------- | --- | ------- | ----- | ----- |
| 十进制（Decimal）      | 10  | 0–9     | 逢十进一  | `102` |
| 二进制（Binary）       | 2   | 0、1     | 逢二进一  | `110` |
| 八进制（Octal）        | 8   | 0–7     | 逢八进一  | `17`  |
| 十六进制（Hexadecimal） | 16  | 0–9、A–F | 逢十六进一 | `1F`  |

> 十六进制里的 `A`=10、`B`=11、`C`=12、`D`=13、`E`=14、`F`=15。

### 3. 为什么电脑用二进制

电脑由电子电路组成，电路最基本的两种状态是：**通电（开）/ 断电（关）**，即**高电平 / 低电平**。
用 `1` 表示「开」，`0` 表示「关」，最简单、最可靠。所以电脑内部一切都用二进制存储。

> 这也是为什么第 1 课说 CPU 只认**机器码**——机器码本质就是一堆 0 和 1。

### 4. 为什么还要学八进制 / 十六进制

- 二进制太长不好读（如 `11111111`）。
- **十六进制正好 4 位二进制 = 1 位十六进制**，八进制 3 位二进制 = 1 位八进制。
- 所以程序员常用十六进制**简写**二进制。例如 `11111111` = `FF`（十六进制）。

### 5. 进制之间的转换

**① 其他进制 → 十进制：按位乘权相加**

以二进制 `110` 为例：

```
1×2² + 1×2¹ + 0×2⁰ = 4 + 2 + 0 = 6
```

所以二进制 `110` = 十进制 `6`。

**② 十进制 → 二进制：除 2 取余，倒着读**

把十进制 `6` 转二进制：

```
6 ÷ 2 = 3 余 0
3 ÷ 2 = 1 余 1
1 ÷ 2 = 0 余 1
```

余数从下往上读：`110`。

### 6. C 语言里怎么写不同进制的数

| 进制   | 写法                | 例子           |
| ---- | ----------------- | ------------ |
| 十进制  | 直接写               | `255`        |
| 八进制  | 以 `0` 开头          | `0377`       |
| 十六进制 | 以 `0x` 或 `0X` 开头  | `0xFF`       |
| 二进制  | 以 `0b` 开头（较新标准支持） | `0b11111111` |

**打印时的占位符：**

| 占位符  | 输出进制                  |
| ---- | --------------------- |
| `%d` | 十进制                   |
| `%o` | 八进制（**o**ctal）        |
| `%x` | 十六进制（he**x**adecimal） |

### 测验与答案

1. 二进制的基数是几？它只用哪两个数字？
   - 参考答案：基数 2；只用 0 和 1。
2. 电脑为什么用二进制？
   - 参考答案：电路只有通/断（开/关）两种基本状态，用 1/0 表示最简单可靠。
3. 二进制 `101` 换成十进制是多少？
   - 参考答案：1×2² + 0×2¹ + 1×2⁰ = 4 + 0 + 1 = 5。
4. C 语言里十六进制 `FF` 怎么写？
   - 参考答案：`0xFF`。

## 补充课（二）：整型数据与实型数据

### 1. 为什么类型要分这么多种

不同类型占用的**内存空间大小不同**，能存的**取值范围**和**精度**也不同。
选合适的类型能省内存、提效率。核心就四个字：**按需选择**。

### 2. 两个基础概念：位与字节

- **位（bit）**：最小的存储单位，一个 0 或一个 1。
- **字节（Byte）**：1 字节 = 8 位（1 Byte = 8 bit）。

### 3. 整型家族（存整数）

| 类型              | 含义   | 常见大小（字节） |
| --------------- | ---- | -------- |
| `short int`     | 短整型  | 2        |
| `int`           | 整型   | 4        |
| `long int`      | 长整型  | 4 或 8    |
| `long long int` | 长长整型 | 8        |

**有符号与无符号**

- `signed`（有符号）：能存**正数、负数、0**（默认）。
- `unsigned`（无符号）：**只能存 0 和正数**，但正数能存的范围**更大**。

```c
unsigned int x = 10;   // 只能非负
```

### 4. 实型家族（存小数，也叫浮点型）

| 类型            | 含义   | 常见大小（字节） | 精度              |
| ------------- | ---- | -------- | --------------- |
| `float`       | 单精度  | 4        | 较低（约 6~7 位有效数字） |
| `double`      | 双精度  | 8        | 较高（约 15~16 位）   |
| `long double` | 长双精度 | 8 或 16   | 最高              |

> 日常写小数**推荐 `double`**：更精确，且运算更方便。

### 5. 用 `sizeof` 查看类型占多少字节

**`sizeof` 运算符**：用来测量某个类型或变量占几个字节。

```c
printf("%d\n", sizeof(int));     // 输出该机器上 int 占的字节数，常为 4
printf("%d\n", sizeof(double));  // 常为 8
```

> 注意：具体大小取决于**操作系统和编译器**，不同环境可能不同，用 `sizeof` 查最准。

### 6. 各类型的 `printf` / `scanf` 占位符

| 类型             | printf | scanf     |
| -------------- | ------ | --------- |
| `int`          | `%d`   | `%d`      |
| `short`        | `%hd`  | `%hd`     |
| `long`         | `%ld`  | `%ld`     |
| `long long`    | `%lld` | `%lld`    |
| `unsigned int` | `%u`   | `%u`      |
| `float`        | `%f`   | `%f`      |
| `double`       | `%f`   | **`%lf`** |

> ⚠️ 重点：`scanf` 读 `double` **必须用 `%lf`**（带字母 l）。而 `printf` 打印 `double` 用 `%f` 即可。这是常见坑。

### 测验与答案

1. `int` 的中文名称是？`float`/`double` 的中文名称是？
   - 参考答案：`int` 叫整型；`float`/`double` 叫实型（浮点型）。
2. 1 字节等于多少位？位是什么？
   - 参考答案：8 位；位（bit）是最小存储单位，一个 0 或一个 1。
3. `unsigned int` 和普通 `int` 的区别？
   - 参考答案：`unsigned` 无符号，只能存 0 和正数，正数范围更大；`int` 有符号，能存负数。
4. 用 `scanf` 读取一个 `double` 变量，占位符应该写什么？
   - 参考答案：`%lf`。

## 第 12 课：`if...else` 和 `else if`

### 1. `if...else`（二选一）

```c
if (条件)
{
    条件成立时执行
}
else
{
    条件不成立时执行
}
```

- `else` = 「否则」。
- 两条路**必走且只走一条**。

例子：

```c
if (score >= 60)
{
    printf("及格了！\n");
}
else
{
    printf("不及格，加油！\n");
}
```

### 2. `else if`（多分支）

```c
if (score >= 90)
{
    printf("优秀\n");
}
else if (score >= 80)
{
    printf("良好\n");
}
else if (score >= 60)
{
    printf("及格\n");
}
else
{
    printf("不及格\n");
}
```

### 3. 关键：从上到下，一匹配就停

程序**从上往下**逐个检查条件，**一旦某个成立，执行它对应的块，整个链就结束**，后面不再检查。

- `score = 85`：`>= 90` 否 → `>= 80` 是 → 打印「良好」，**结束**。
- 所以**条件顺序很重要**：若把 `>= 60` 放最前，85 会先命中「及格」，永远轮不到「良好」。

### 4. 花括号可以省吗

只有**一条语句**时可省略：

```c
if (score >= 60)
    printf("及格\n");
else
    printf("不及格\n");
```

> **建议新手始终写 `{}`**，避免以后加代码出错。

### 测验与答案

1. `if...else` 两条分支会同时执行吗？
   - 参考答案：不会，只会走其中一条。
2. `score = 95` 时下面打印什么？为什么？
   
   ```c
   if (score >= 90) printf("优秀\n");
   else if (score >= 60) printf("及格\n");
   else printf("不及格\n");
   ```
   - 参考答案：打印「优秀」；95 ≥ 90，第一个条件就命中，随即结束。
3. 对错：多个 `else if` 会检查完所有条件再决定。
   - 参考答案：错；从上到下依次检查，**命中一个就停**。

## 第 13 课：循环结构 `while`

### 1. 为什么需要循环

要打印 1 到 100，总不能写 100 行 `printf`。**循环结构（Loop / Iteration）** 让一段代码**反复执行**，直到条件不满足才停。

### 2. `while` 写法

```c
while (条件)
{
    重复执行的代码
}
```

只要**条件成立**就执行循环体；执行完**回头再判断**，条件不成立就跳出。

### 3. 例子：打印 1 到 5

```c
#include <stdio.h>

int main()
{
    int i = 1;              // ① 起点

    while (i <= 5)          // ② 条件
    {
        printf("%d\n", i);  // ③ 做事
        i = i + 1;          // ④ 更新（可写 i++）
    }

    return 0;
}
```

### 4. 循环的三个必备零件

| 零件 | 例子 | 作用 |
|------|------|------|
| **起点（初始化）** | `int i = 1;` | 从哪开始 |
| **条件（终止条件）** | `i <= 5` | 什么时候停 |
| **更新（步进）** | `i = i + 1;` | 每次怎么变，最终让条件不成立 |

> 忘了「更新」→ `i` 永远不变 → 条件永远成立 → **死循环（Infinite Loop）**，程序卡死。

### 5. `i++` 与 `i--`

| 写法 | 含义 |
|------|------|
| `i++` | `i = i + 1` |
| `i--` | `i = i - 1` |

### 6. 例子：算 1 到 100 的和

```c
int sum = 0;
int i = 1;

while (i <= 100)
{
    sum = sum + i;   // 可写 sum += i
    i++;
}

printf("1到100的和是 %d\n", sum);   // 5050
```

### 测验与答案

1. `while` 循环必备的三个零件？
   - 参考答案：起点（初始化）、条件（终止条件）、更新（步进）。
2. 忘了写「更新」会怎样？
   - 参考答案：变成死循环，程序停不下来。
3. `i = i + 1;` 的简写？`i--` 是什么意思？
   - 参考答案：`i++`；`i--` 表示 `i = i - 1`。
4. 下面打印几行、什么？`int i = 3; while (i > 0) { printf("hi\n"); i--; }`
   - 参考答案：3 行，每行 `hi`。

## 第 14 课：`for` 循环

### 1. 为什么有 `for`

`while` 的三个零件（起点、条件、更新）分散在代码各处，容易漏看。`for` 把它们**集中写在一行**，更紧凑，实际中**最常用**。

### 2. 写法

```c
for (起点; 条件; 更新)
{
    循环体
}
```

打印 1 到 5：

```c
for (int i = 1; i <= 5; i++)
{
    printf("%d\n", i);
}
```

| 位置 | 内容 | 对应 `while` |
|------|------|-------------|
| 第 1 段 | `int i = 1` | 起点 |
| 第 2 段 | `i <= 5` | 条件 |
| 第 3 段 | `i++` | 更新 |

三段用**分号**隔开；第 3 段 `i++` **后面不写分号**。

**执行顺序：** 起点（只一次）→ 判断条件 → 循环体 → 更新 → 再判断……直到条件不成立。

### 3. `for` vs `while`

- **知道循环次数** → 用 `for`（更简洁）。
- **不知道次数，只知道满足条件就一直做** → 用 `while`。

### 4. 例子：算 1 到 100 的和

```c
int sum = 0;

for (int i = 1; i <= 100; i++)
{
    sum += i;
}

printf("1到100的和是 %d\n", sum);   // 5050
```

### 测验与答案

1. `for` 三段分别对应 `while` 的什么？用什么隔开？
   - 参考答案：起点、条件、更新；用分号隔开。
2. `for (int i = 0; i < 4; i++) printf("%d ", i);` 打印什么？
   - 参考答案：`0 1 2 3`（从 0 开始，共 4 个）。
3. 判断用 `for` 还是 `while`： (a) 打印乘法表前 9 行；(b) 一直让用户输密码直到输对。
   - 参考答案：(a) `for`；(b) `while`。

## 第 15 课：`break` 和 `continue`

### 1. 作用

- **`break`**：**立刻彻底跳出**整个循环，后面的循环不再做。
- **`continue`**：**跳过本次**剩下的代码，直接进入**下一次**循环。

### 2. `break` 例子：找到第一个能整除 7 的数

```c
for (int i = 1; i <= 100; i++)
{
    if (i % 7 == 0)
    {
        printf("找到 %d\n", i);
        break;
    }
}
```

输出 `找到 7`，找到即退出。

### 3. `continue` 例子：打印 1 到 5，跳过 3

```c
for (int i = 1; i <= 5; i++)
{
    if (i == 3)
    {
        continue;
    }
    printf("%d\n", i);
}
```

输出 `1 2 4 5`（3 被跳过，循环继续）。

### 4. 对比

| 关键字 | 作用 | 打比方 |
|--------|------|--------|
| `break` | **彻底结束**整个循环 | 直接离场 |
| `continue` | **跳过本次**，继续下一轮 | 跳过这一项，接着做后面的 |

> 记忆：`break` = 打破（整个循环）；`continue` = 继续（下一轮）。

### 测验与答案

1. `break` 与 `continue` 的核心区别？
   - 参考答案：`break` 彻底结束整个循环；`continue` 只跳过本次，继续下一轮。
2. `for (i=1;i<=5;i++){ if(i==2) continue; if(i==4) break; printf("%d ",i); }` 打印什么？
   - 参考答案：`1 3`。
3. 对错：`continue` 会让整个循环结束。
   - 参考答案：错，只跳过本次迭代。

## 第 16 课：数组（Array）

### 1. 为什么需要数组

存一个班 50 个成绩，用 50 个变量太笨。**数组**用**一个名字**管理一串**相同类型**、**连续排列**的数据。

### 2. 声明数组

```c
int scores[5];
```

创建一个叫 `scores` 的整数数组，能装 **5 个**整数。
- `[5]` 是**数组长度**（能装几个）。
- 所有元素**类型必须相同**。

### 3. 下标（Index）从 0 开始

```c
int scores[5];

scores[0] = 90;   // 第 1 个
scores[1] = 85;   // 第 2 个
scores[2] = 78;   // 第 3 个
```

> ⚠️ **最重要**：下标从 `0` 开始。长度 5 → 下标 `0 1 2 3 4`，**没有 `scores[5]`**。
> **n 个元素，下标 0 到 n-1。** 用更大的下标去访问叫**越界（Out of Bounds）**，是严重错误。

### 4. 声明时直接初始化

```c
int a[5] = {10, 20, 30, 40, 50};
```

值依次放入各格子。也可省略长度：

```c
int a[] = {10, 20, 30};   // 自动确定长度为 3
```

### 5. 配合循环使用（经典套路）

```c
#include <stdio.h>

int main()
{
    int a[5] = {10, 20, 30, 40, 50};

    for (int i = 0; i < 5; i++)     // i 从 0 到 4
    {
        printf("%d\n", a[i]);
    }

    return 0;
}
```

注意条件是 `i < 5`（不是 `i <= 5`），因为最大下标是 4。

> **循环变量 `i` 天然适合当下标**，从 0 数到 n-1。

### 测验与答案

1. 长度为 6 的数组，合法下标？为什么不是从 1 开始？
   - 参考答案：`0 1 2 3 4 5`；C 语言规定下标从 0 开始。
2. 对错：`int a[3];` 之后可以写 `a[3] = 5;`？
   - 参考答案：**错**。长度 3 的合法下标是 0、1、2，`a[3]` 越界。
3. 声明能装 4 个整数的数组，值设为 1、2、3、4。
   - 参考答案：`int a[4] = {1, 2, 3, 4};`。
4. 下面打印几个数？`int a[3] = {7,8,9}; for(int i=0;i<3;i++) printf("%d ",a[i]);`
   - 参考答案：3 个数：`7 8 9`。

## 第 17 课：函数（Function）

### 1. 为什么需要函数

`main()`、`printf()`、`scanf()` 都是函数。**函数**是一段打包好、有名字、可重复使用的代码，用来完成某个任务。
好处：**复用**（写一次到处调）、**清晰**（把大程序拆成小任务）。

### 2. 函数的结构

```c
int add(int a, int b)
{
    return a + b;
}
```

| 部分 | 例子 | 含义 |
|------|------|------|
| 返回类型 | `int` | 返回结果的类型 |
| 函数名 | `add` | 调用时用它 |
| 参数列表 | `(int a, int b)` | 传进来的数据（**参数 Parameter**） |
| 函数体 | `{ return a + b; }` | 具体做什么 |
| `return` | `return a + b;` | 把结果返回给调用者 |

### 3. 定义 + 调用

```c
#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main()
{
    int result = add(3, 5);   // 调用，传入 3、5
    printf("%d\n", result);   // 8
    return 0;
}
```

> 传进去的 `3`、`5` 叫**实参（Argument）**；定义里的 `a`、`b` 叫**形参（Parameter）**。

### 4. 没有返回值：`void`

```c
void sayHello()          // 无参数、无返回
{
    printf("你好！\n");
}

int main()
{
    sayHello();
    return 0;
}
```

`void` = 空，表示「没有」。

### 测验与答案

1. 函数由哪几部分组成？
   - 参考答案：返回类型、函数名、参数列表、函数体（含 `return`）。
2. `return` 的作用？
   - 参考答案：把函数的结果返回给调用者。
3. 只做事、不需要返回结果，返回类型写什么？
   - 参考答案：`void`。
4. `int square(int x){return x*x;} printf("%d\n", square(4));` 输出什么？
   - 参考答案：`16`。

## ★ 难点大白话回顾（数制 / 整型 / 实型）

### 数制：其实就是「数到几就进位」

- 十进制：满 10 进 1，用 0–9（因为人有 10 根手指）。
- 二进制：满 2 进 1，只用 0、1（因为电脑电路只有「通 / 断」两种状态）。
- 十六进制：满 16 进 1（程序员用，因为写起来短：4 位二进制 = 1 位十六进制）。

> 一句话：**进制 = 进位规则不同**，本身不神秘。

### 整型 / 实型：就是两种「盒子」

- 整型盒子：只能装**整数**（如 `3`、`-5`）→ `int`。
- 实型盒子：能装**小数**（如 `3.14`）→ `double`。

盒子还分大小，像水杯分大小：

- `short` / `int` / `long`：小杯 / 中杯 / 大杯，都是装整数，只是**范围**不同。
- `float` / `double`：普通量杯 / 高精度量杯，都是装小数，只是**精度**不同。

> **现阶段只记两个**：装整数用 `int`，装小数用 `double`。其余以后再说。
