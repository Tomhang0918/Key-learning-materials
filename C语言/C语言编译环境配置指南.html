C 语言编译环境配置指南

三条路线任选：① Dev-C++（学习通安装包，Windows 教学统一环境）② 在线编译器（零安装，Mac 适用）③ VS Code 本地完整版（进阶）。同一份 .c 代码全部通用。

Windows macOS 编译器分别用 gcc (MinGW-w64) 与 clang (Xcode 命令行工具)，功能等价。

一句话：VS Code 只是「写代码的编辑器」，真正把 C 变成程序的是编译器。Windows 装 MinGW-w64，Mac 装 Xcode 命令行工具，再装一个 C/C++ 扩展，就能跑了。

🟢 新生极简路线（推荐先看这个）

别被下面那一大篇吓到。两条极简路：Windows 直接装学习通里的 Dev-C++ 安装包（自带编译器，装完按 F11 就跑）；Mac 或临时写代码用在线编译器（开网页即用）。都不用配环境、不用敲命令。
路线适合安装量上手
① Dev-C++（学习通下载，Windows）所有 Windows 同学（教学统一环境）1 个安装包，下一步到底3 分钟
② 在线编译器（OnlineGDB / Programiz）Mac 同学、临时写、怕麻烦0（开网页即用）1 分钟
③ VS Code 本地完整版（下文）想搞懂编译/调试、长期用装软件+编译器+配环境15 分钟
老师建议：上课统一用 Dev-C++，安装包就在学习通「课程材料和软件」里（Dev-Cpp_5.11_TDM-GCC_4.9.2_Setup.exe，自带 TDM-GCC 编译器）。家里用 Mac 或嫌麻烦的同学，走路线②在线编译器，代码和 Dev-C++ 完全通用，作业复制过去就能交。

路线①：Dev-C++（教学统一环境，Windows）

1
登录学习通 → 课程 → 「课程材料和软件」，下载 Dev-Cpp_5.11_TDM-GCC_4.9.2_Setup.exe（推荐，自带编译器）；或 Dev-Cpp5.4.0.zip 绿色版，解压即用。
2
双击安装包一路「下一步」。TDM-GCC 编译器已打包在内，不用另装编译器、不用配 PATH。安装器没中文没关系，装完可切。
3
打开 Dev-C++：「File → New → Source File」写代码，保存为 .c，按 F11 编译并运行（F9 只编译、F10 只运行），弹窗看输出。
想要中文界面：装完后 Tools → Editor Options → General → Language 选 Chinese。常见中文报错见本目录《DevC中文报错方案》。Dev-C++ 没有 Mac 版，Mac 同学请走路线②。

路线②：在线编译器（Mac / 零安装）

1
浏览器打开 https://www.onlinegdb.com（或 https://www.programiz.com/c-programming/online-compiler），左上角语言选 C。
2
左边写代码（示例可清空重写），写完点绿色 Run 按钮，右边出结果。
图 0：在线编译器界面（示意图：左边写代码，右边出结果，点 Run 即可）
优点：Win / Mac / 手机 / 平板都能用，不用装任何东西，不怕环境配错。缺点：要联网；多文件大作业不方便（那时再学本地版）。

路线③：VS Code 本地完整版（进阶 / 想学编译原理用）

下面这部分需要装编译器、配环境变量、敲终端命令。新生如果只想把作业跑起来，看完路线①或②就够了，可以跳过这一节。

1. 安装 VS Code（两平台一样）

1
打开官网 https://code.visualstudio.com，点页面中央的 Download。网站会自动识别你的系统（Windows 给 .exe，Mac 给 .zip）。
图 1：VS Code 官网下载页（示意图）
2
Windows：双击 .exe，一路「下一步」，建议勾选 “添加到 PATH” 和 “添加到右键菜单”。
Mac：解压 .zip，把 Visual Studio Code.app 拖进「应用程序」文件夹即可。

2. 安装 C/C++ 扩展（两平台一样）

1
打开 VS Code，按 Ctrl+Shift+X（Mac 用 Cmd+Shift+X）打开扩展栏，搜索 C/C++，安装微软出品的那一个（作者 Microsoft，下载量最高）。
图 2：安装 Microsoft「C/C++」扩展（示意图，深色界面为 VS Code 默认）

3. 安装编译器（两平台不同）

Windows 装 MinGW-w64

1
推荐用 MSYS2：官网 https://www.msys2.org 下载安装，装完打开「MSYS2 UCRT64」终端。
2
在终端执行：
pacman -S --needed base-devel mingw-w64-ucrt-x86_64-gcc
3
把 C:\msys64\ucrt64\bin 加入系统 PATH 环境变量，然后重开所有终端/VS Code。
嫌 MSYS2 麻烦？可直接下 winlibs 的 zip 包（winlibs.com），解压后把里面的 bin 目录加入 PATH 即可，无需安装器。

macOS 装 Xcode 命令行工具

1
打开「终端」（启动台搜 Terminal），输入一行命令：
xcode-select --install
2
弹窗点「安装」，等进度条走完（约几分钟）。这就装好了 clang 编译器。
不用装完整的 Xcode（几个 GB）。命令行工具只有几百 MB，足够写 C 语言课程所有程序。
✓
验证安装：打开 VS Code 的集成终端（Ctrl+` 反引号，Mac 用 Cmd+`），分别输入下面命令，能看到版本号就成功了。
图 3：在集成终端验证编译器（示意图）

4. 写第一个程序

1
新建文件夹（如 hello），用 VS Code 打开它（菜单「文件 → 打开文件夹」）。
2
在左侧资源管理器点「新建文件」，命名为 hello.c，输入下面的代码：
#include <stdio.h>

int main() {
    printf("Hello, C!\n");
    return 0;
}
图 4：在 hello.c 里写代码（示意图，含语法高亮）
记住：写完后按 Ctrl+S（Mac Cmd+S）保存。不保存就编译，跑的是旧文件。

5. 编译并运行（两平台命令不同）

打开集成终端（Ctrl+`），先 cd 到文件所在目录，再执行编译命令。

Windows · gcc

gcc hello.c -o hello
hello

首行把 hello.c 编译成 hello.exe；第二行运行它。也可合并成一行：

gcc hello.c -o hello && hello

macOS · clang

clang hello.c -o hello
./hello

注意 Mac 运行要加 ./ 前缀（表示「当前目录」）。也可合并：

clang hello.c -o hello && ./hello
图 5：编译并运行，输出 "Hello, C!"（示意图）
偷懒法（可选）：装扩展 Code Runner，右上角出现 ▶ 按钮，点一下自动编译运行，不用记命令。但学 C 语言建议先用手敲命令，理解「编译 → 运行」两步，考试和排错都用得上。

报错现象原因解决办法

7. 和 Dev-C++ 的关系

重点：同一份 .c 文件，Dev-C++ 和 VS Code 都能编译，代码 100% 通用。
你在课上用 Dev-C++ 写的作业，拿到 Mac 上用 VS Code + clang 一样能跑；反过来也一样。区别只在「谁帮你按下了编译按钮」，底层都是标准 C 编译器。

所以：Windows 同学直接用学习通里的 Dev-C++ 安装包；Mac 同学走路线②在线编译器（或进阶路线③ VS Code），作业代码直接复制过去就能交。
